# Local Resolution Report

This report measures how many dataset URLs the cache and URL stage settles
before the page is opened, and how often those verdicts match the dataset label.

## 1. Method

Each URL's signals come from `UrlSignals` (the blocklist, brand imitation in the
host, and a URL that is itself an `.apk` file), and the URL counts as resolved when
the verdict table (`ml/runtime/verdict_table.json`) says the result is final
whatever the page and the model would show. A resolved verdict is correct when
its risk equals the dataset label. Every URL is judged independently, so the
store is excluded; the unresolved count is what goes on to open the page.

The report is generated by `LocalResolutionReportWriter`:

```bash
./gradlew :core:llm:writeLocalResolutionReport
```

## 2. URL Dataset

All rows of the committed URL dataset. Of 668 rows, 30 (4.49%) are settled by the URL alone, and 30 of those (100.00%) match the label. The remaining 638 go on to open the page.

| Settled by | Resolved | Correct | Correct / resolved |
| :-- | --: | --: | --: |
| `.apk` file off the brand's site | 30 | 30 | 100.00% |
