# Local Resolution Report

This report measures how many dataset URLs the local pipeline resolves before
page-content inspection or remote fallback, and how often those local verdicts
match the dataset label.

## 1. Method

Each URL runs through `RuleBasedJudge`, `OnDeviceModelJudge`, and
`LocalKnowledgeJudge` in pipeline order and counts as resolved at the first
`CERTAIN` verdict; a resolved verdict is correct when its `risk` equals the
dataset label. Every URL is judged independently, so the store is excluded.
`PageContentJudge` is also excluded because it needs a real WebView; the
unresolved count is therefore what reaches page-content inspection or remote
fallback.

The report is generated by `LocalResolutionReportTest`:

```bash
GUADIAN_WRITE_LOCAL_RESOLUTION_REPORT=1 ./gradlew :app:testDebugUnitTest \
  --tests com.guardian.ondevice.judge.LocalResolutionReportTest
```

## 2. Holdout Split

The holdout split was not seen in training. Of 132 rows, 53 (40.15%) resolve locally, and 34 of those (64.15%) match the label. The remaining 79 continue to page-content inspection or remote fallback.

| Stage | Resolved | Correct | Correct / resolved |
| :-- | --: | --: | --: |
| Deterministic rules | 29 | 17 | 58.62% |
| On-device model | 8 | 7 | 87.50% |
| Local knowledge | 16 | 10 | 62.50% |

## 3. Full Dataset

The full dataset includes the training rows, so model results here are optimistic. Of 668 rows, 249 (37.28%) resolve locally, and 186 of those (74.70%) match the label. The remaining 419 continue to page-content inspection or remote fallback.

| Stage | Resolved | Correct | Correct / resolved |
| :-- | --: | --: | --: |
| Deterministic rules | 138 | 99 | 71.74% |
| On-device model | 45 | 44 | 97.78% |
| Local knowledge | 66 | 43 | 65.15% |
